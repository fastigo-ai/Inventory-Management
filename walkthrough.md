# Standardize JMC and WIP Export Formats

I have standardized the export formats across JMC, WIP Required, and WIP Consumed to match the import template structure exactly.

## Changes Made
1. **JMC Export (`backend/src/modules/jmc/jmc.export.ts`)**:
   - Refactored logic to query all master items for activities present in the JMC records.
   - Grouped the items by `Activity` and rendered them with an Activity Header row.
   - Included all items for those activities, showing `0` (or blank) if the item is not claimed in the JMC, ensuring exact parity with the new auto-fill logic in the UI.
2. **WIP Consumed Export (`backend/src/modules/wip/wip.export.ts`)**:
   - Updated the export logic to follow the exact same matrix layout as JMC (grouped by Activity, includes 0-value items, WIPs as columns).
3. **WIP Required Export (`backend/src/modules/wip-required/wipRequired.export.ts` & Frontend)**:
   - Created a new backend export API for WIP Required (copied and adjusted from WIP Consumed).
   - Switched the frontend `exportData` function to download the `.xlsx` file generated by the backend instead of manually building a flat `.csv` list.

## Validation
- ✅ Validated that the backend builds successfully (`npm run build`).
- ✅ Validated that the frontend builds successfully (`npm run build`).

You can now test the export functionality in the JMC, WIP Required, and WIP Consumed portals. The downloaded Excel sheets should exactly mirror the visual structure of your import templates!
